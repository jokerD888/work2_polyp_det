## 评估分工

- Kvasir Train：训练模型及训练期Mask监督。
- Kvasir Val：按既定最高bbox AP规则选checkpoint，并作辅助工程/源域检查。
- PolypGen：主测试集；总体bbox AP和分中心表现是实用收益的主要评价，主要错误类型也在此检查。
- PolypsSet/PolypDB：当前仍未参与，后续安排不因本次澄清改变。

研究中阅读主测试错误与按其分数反复调权、重选checkpoint是不同操作。本次复用已有固定A/B产物，只做观察性错误分析；不修改checkpoint、分数、阈值或训练配置。数据集称呼修正不意味着把已观察结果改称从未接触的盲测。

## 对理论判断的修正

1. **新颖性审查仍成立。** 已有Mask选样、可靠样本引导、局部环带对比的文献重叠不因主测试集更换而消失；不能直接把普通Local-R称作第二创新。
2. **性能优先级需要主测试证据。** 不再用Kvasir单框只有3例几何缺失，推断局部关系不值得投入。PolypGen目前有184例单框候选缺失，且低颜色对比组更困难，足以保留局部关系的研究优先级；同时不能忽略尺度和多目标问题。
3. **颜色只是代理。** 即使PolypGen低颜色对比组更困难，也不等于证明特征混淆或对比loss必然有效；还要区分中心、面积、Mask有效性及候选阶段。
4. **实现仍以检测为目标。** 若进入机制验证，挂载检测共享特征、比较成熟FG/BG对照，以PolypGen bbox AP检验效果；Kvasir Val维持原选权职责。
