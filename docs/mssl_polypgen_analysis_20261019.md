## 本次补充什么

1. **严格覆盖。** 在 IoU=.50/.75/.80/.85/.90/.95、Top-K=1/5/10/100 下计算阈值约束最大基数二分图匹配。不能用贪心或最大总 IoU 匹配代替；单个预测最多匹配一个 GT。
2. **检索排名。** 记录每个 GT 的首个兼容候选排名，在双方均有兼容候选的同一集合比较，同时报告只有一方有候选的数量。该逐 GT 排名本身不作排他匹配，不能混称严格召回。
3. **几何与评分路径。** 对四个冻结检查点做 `eval()`+`no_grad()` 原生图像前向，观察原生分类分数、Mask 质量和选中的 Query ID，并保存全部 300 个 Query 的框。所有 1473 张图像的原生预测逐一核对，容差为框 1e-3px/rtol1e-5、分数 1e-6/rtol1e-5。观察器调用原生推理，不替换其输出。
4. **分数反事实。** 对原来同一批100个候选、原始保存框，单独使用分类分数重算 AP。它只用于诊断排序/分数尺度变化，不作为新部署方案；不能和几何效应作唯一可加的因果分解。
5. **误检/漏检和四边误差。** 固定原有 score≥.5 作为诊断点，保留负图；四边误差用四个模型共同覆盖的同一 GT 集合。最大匹配下的 TP/FP 与官方 COCO 按分数贪心的 TP/FP 规则不同，会明确区分。
6. **不确定性。** 2000 次六中心内按图像分层配对 Bootstrap；每次四组共用同一抽样多重集合，中心规模固定，报告点估计和百分位95%差值区间。区间包含零时不宣称正增益已被统计确认，多指标区间不进行事后挑选。
7. **分组与敏感性。** 分中心、六次留一中心、排除全部四张重复冲突图像的既定协议敏感性。

## 重采样的正确性

同一图像被抽中多次，语义上生成独立 image ID 与 annotation ID 的副本，同步复制 GT 和预测。为避免每次重新匹配开销，代码缓存官方 COCOeval 的图像内匹配；每次仍按副本重建全局分数顺序、TP/FP、召回和101点精度包络，不平均单图 AP。
同分预测的稳定排序也被保留：同一图像内同分的多个预测按每个副本的原次序重复，而非逐检测简单加权。合成反例、负图和重复ID检查通过后，四个模型原始全量点估计以及前两次真实全量重采样再与分配新 ID 的官方 COCOeval 核对，最大允许 AP 绝对误差 1e-12。

附带 C1–C5 CSV 中未找到患者/视频 ID 字段，C6 未提供同类 CSV；不从文件名推断患者。因此区间仅是条件于已观察六中心的图像级区间，未知患者内相关可能使区间偏窄，不能当作患者级或训练 Seed 级不确定性。具体文件、字段、行数及哈希见 group_audit.json。
