## 实验定义

| 组别 | 额外定位项 | 状态 |
|---|---|---|
| baseline | 无 | 已有 50 epoch 结果，复用 |
| MSSL | 精细 GT Mask 支持的 CDF 差半平方 | 已有 50 epoch 结果，复用 |
| Box-CDF | 相同 CDF，支持改为提供的 GT Box 矩形 | 已完成训练、验收及评估 |
| Mask-static | 精细 Mask 支持，CDF 换成自身局部二阶近似 | 已完成训练、验收及评估 |

四组都保留原生 Mask Loss、L1/GIoU、匹配、DN 和推理路径。Box-CDF 仅替换额外损失的支持，不是无 Mask 的训练。
原始多框图像和空 Mask 的额外损失排除规则保持一致。沿用原始矩形的连续单元占比，避免取整制造边界差异。

令 d=(预测边−提供的 GT 边)/max(GT 对应轴尺寸,4px)，G(d)=F(e*+sd)。

```
CDF:    0.5 * (G(d)-G(0))^2
static: 0.5 * Gprime(0)^2 * d^2
```

静态系数只由 GT 计算并停止梯度。四边平均、有效目标平均、额外项权重 1.0 保持一致。
静态版本无界；CDF 有界且可能饱和。若静态版数值不通过，不自动加裁剪、降权或搜索新参数，链路停止并保留失败记录。

## 保持的训练条件

配置从实际已训练 MSSL 的 `experiment.json` 复制，对模型、数据、优化器配置、运行时、Seed、预算、权重选择规则逐项校验。

- Seed 42，Kvasir 官方 880/120 划分，50 等效 epoch=2750 个优化器迭代。
- 原有 ImageNet R50 初始化；1024 LSJ；AdamW 1e-4；原生损失系数及学习率衰减。
- 单 GPU microbatch 1，梯度累积 16；与既有两组一致，并非物理 batch16 的数学等价替代。
- 每 275 步评估，按源域 val bbox AP50:95 最大值选择权重，平分取最早；不按 AP75 或外测选权重。
- 额外损失权重、温度、方向带宽保持 1.0/0.05/0.15；不匹配结果调权，不用 PolypGen 调参。
- AMP 跳步和成功更新数持续记录；迭代预算相同不保证各损失下跳步数相同。

## 诊断与验收

15 项专项检查已在工作区通过，覆盖：与实际训练冻结版本的 CDF 损失/梯度逐位一致、静态局部近似、原生损失/RNG 一致、梯度探针不改变 RNG 或最终反向梯度、一对一候选匹配和标注不一致处理。
冻结副本内另跑专项检查；历史快照对比项需要原工作区的历史材料，在冻结副本中会跳过，该项的工作区检查已通过。

正式训练前，对三张预先固定的源域训练单框 GT，画出三种损失与 dL/dd 在 [-1,1] 上的曲线，四边分别绘制，导出 PNG/PDF 和数值 JSON。
Box-CDF 和 Mask-static 各自运行真实 GPU 检查：共享数据管线、105 项原生损失及 RNG 一致、额外项到实际框头的非零梯度、AMP 完整反向与一次有效优化器更新、图像单独推理一致性。

在新增训练的迭代 0、10、275*k 的第一个微批次，记录同一前向/同一匹配下三种额外损失和原生最终层加权 L1+GIoU 对共享框回归 MLP 的梯度范数。探针不更新参数、不抽随机数、不累加 `.grad`；范数是 AMP 缩放/裁剪前、未做跨微批次累积的局部诊断。

为降低 AMP 图上未缩放反向的 FP16 下溢，诊断反向固定乘 64，在 FP32 中除回后计算范数；这不改变训练 GradScaler。仍可能受有限精度影响，零范数不能单独解释为饱和。首次短启动发现该测量问题后已停止，仅保留为 `runs/mssl-attribution-20261018/` 的历史记录；正式归因使用新的 `runs/mssl-attribution-20261018-r2/` 冻结链路，从相同 Seed 和初始化重新训练，不接续历史短启动权重。

旧两组及新两组的最佳源域权重另外在相同 16 张固定训练图像、相同 LSJ 种子下重放。只计算损失和梯度，不进行训练。检查点局部表现不能重建旧训练历史。
CDF 弱斜率定义为 Gprime(d)<0.01*Gprime(0)，另列 |d|>0.05，避免把近正确坐标的低损失梯度误称饱和。

预测分析包括逐 IoU 阈值 AP、top-1/top-10/top-100 候选覆盖、固定 score≥0.5 的 TP/FP 诊断、双方共同覆盖目标的四边有符号/绝对误差。
一对一最大总 IoU 匹配保留所有固定 GT，漏检记零；共同匹配误差必须结合覆盖数解读，不用于替代 COCO AP。

仅在原始单框图像计算语义 Mask 几何：框内 Mask 占比、总 Mask/Box 面积比、紧致度、四个框内 0.15 轴宽条带的支持密度、Mask 外接框与提供 GT Box 的 IoU、面积和长宽比。
记录 Spearman、面积分层及控制 log面积/log长宽比/基线 IoU 的描述性回归；不根据关联宣称因果。PolypGen 的形态分析仅作事后解释，不用于参数或方法选择。
