# MSSL下一阶段：最终层IA-BCE质量对齐的最小对照

日期：2026-10-20。状态：方案获准，IA-BCE-Final已实现；工程验收与有限后台训练队列见[执行记录](ia_bce_final_execution_20261020.md)。下文保留预先确定的研究规格，冻结MSSL V1与已完成模型保持原样。

## 1. 本轮只回答一个问题

在当前共同MaskDINO协议下，一个已有、可审计的Box质量感知分类组件是否有独立收益；它与MSSL是否有值得继续研究的增量关系？

依据[源域诊断](results/mssl_quality_source_20261020.md)：MSSL在预定阈值下300→100覆盖无损失，18/112个多候选GT的组内最高分框距最好框IoU至少差0.05；仅组内交换原分数使AP增加2.632点。该GT参照不可部署，也不保证学习效果。全300在IoU≥0.90仍有59/130个GT未覆盖，不预设质量排序为唯一或主要瓶颈。

因此先研究最终分类置信度与定位质量的对齐，不增加独立质量头、不改Encoder筛选或多对一匹配。目标是可证伪的组件移植，不将成熟方法移植本身列为新创新。

## 2. 选定组件及版本边界

推荐实验名 **IA-BCE-Final**：采用作者仓库固定版本 `IA_BCE_loss` 在单匹配、rank=0、rank_weight=1时的分类分量，只替换MaskDINO最终普通Decoder层的分类损失。

- [作者仓库](https://github.com/FelixCaae/AlignDETR)，固定commit：`4b125f7fe2ff8c3468cd71763fcf971d09ee38db`。
- [固定参考函数](https://github.com/FelixCaae/AlignDETR/blob/4b125f7fe2ff8c3468cd71763fcf971d09ee38db/aligndetr/losses/losses.py)，路径 `aligndetr/losses/losses.py`，SHA256：`e70e64f589586d516221eb19c70536bd97eae34d385686a691e33378b15d0ebd`。
- 核对作者 `many_to_one_criterion.py`、`two_stage_criterion.py` 和R50配置：quality alpha=0.25、negative gamma=2，最后Decoder保持单匹配。源码与来源清单保留在本地忽略的 `research/quality_alignment_20261020/`。
- [BMVC 2024正式论文](https://bmva-archive.org.uk/bmvc/2024/papers/Paper_211/paper.pdf)定义的Align Loss包含对软目标的focal型正负调制；固定仓库 `IA_BCE_loss` 对匹配正样本使用普通软BCE，两者不能混称为同一公式。仓库还有不同的base criterion写法，不混用这些路径。

选择该组件的理由是无新增预测参数、单匹配退化形式清楚、能够保持原MaskDINO推理及已有监督。它不是最新最强对照，也不是完整Align-DETR复现。Rank-DETR等完整方案同时涉及架构、损失与匹配，本轮不整体移植。若后续选择正式论文Align Loss，应在读取新训练指标前作为另一份明确定义的协议决定，不能运行后换版本择优。

## 3. 固定公式与作用范围

令最终普通Decoder输出logit为z、p=sigmoid(z)，对该层原生Hungarian已匹配的正样本，u为当前预测框与分配GT框的真实IoU。定义：

```
t = stop_gradient(max(p**0.25 * u**0.75, 0.01))
L_positive = BCEWithLogits(z, t)
L_negative = p**2 * BCEWithLogits(z, 0)
L_Q = (sum_positive L_positive + sum_unmatched L_negative) / native_num_boxes
```

同类多个候选中仍只有原生匹配者为正，其余保持负样本；不将所有高IoU框都标为阳性。t的整条计算链停止梯度，包括p和u；负项p²不停止梯度，沿用参考函数。quality alpha不是原生focal loss的类别平衡alpha，不额外套用0.25/0.75平衡因子。

FP32计算IoU与损失；使用BCEWithLogits/softplus替代直接log(sigmoid)，在有限非饱和区校验数学值和梯度等价，并明确饱和区原代码的0×log(0)数值问题。不裁剪logit或移动框坐标。质量下限0.01来自该固定参考代码，不是本机调参。原num_boxes归一化保留；不能因参考归约形式差异多除或多乘300。

| 项目 | 本轮约定 |
|---|---|
| 最终普通Decoder分类 | 原loss_ce替换为L_Q，保留原权重4；不是在其上再叠加一个分类损失 |
| 正样本 | 所有原生有效匹配GT；不沿用MSSL额外损失的单框可靠性筛选 |
| 辅助Decoder/Encoder/interm/DN分类 | 全部保留原生focal；不扩展Q到这些分支 |
| Matching | 原生类别、Box、Mask成本及调用路径不变；复用该层实际匹配结果，不重做Hungarian或随机采样 |
| 原生Box与Mask损失 | 保留L1/GIoU、Mask/Dice、DN及原归一化和权重 |
| MSSL开关 | Q组关闭；MSSL+Q组沿用V1所有常数、适用GT和最终层附加损失 |
| 参数与推理 | 无新增头/参数；原生分类Top100及class×Mask质量融合，保留100输出、无新增阈值/NMS/TTA |
| 损失尺度 | 记录加权正负项及共享分类头梯度，不据此临时搜索权重；原权重相同不等于梯度强度配平 |

固定的是算法规则，不是训练后的Query身份或框坐标。Q训练会经共享特征和分类分数影响其他输出及后续匹配；不能宣称该实验是仅改变测试排序的纯干预。

## 4. 最小实验矩阵与公平性

| 组 | MSSL | 最终IA-BCE | 处理 |
|---|---|---|---|
| A：Baseline | 关 | 关 | 复用冻结结果 |
| B：MSSL V1 | 开 | 关 | 复用冻结结果 |
| C：IA-BCE-Final | 关 | 开 | 新增完整训练 |
| D：MSSL+IA-BCE-Final | 开 | 开 | 新增完整训练 |

只新增C、D；两组都从共同ImageNet R50初始化重新训练，不从A/B最佳权重接续。沿用实际880/120数据与raw Mask管线、Seed42、1024 LSJ、50等效Epoch、2750预定迭代、microbatch1×累积16、原优化器/AMP/学习率及衰减；每275迭代按源域最大bbox AP50:95选权重，同分取最早。记录实际成功更新和AMP跳步，不保证各组跳步数相同。

C、D在启动前同时固定配置、唯一实现版本及顺序，不看C的AP后调整D。旧结果复用前核对新代码关闭Q时与实际训练版本的输出、损失及数据协议一致。

该矩阵回答MSSL与Q的作用和描述性交互，不能直接证明精细Mask改善质量估计；Box-CDF+Q未包含，仍不能据此建立Mask相对矩形支持的特定增量。

## 5. 正式训练前的验收

1. 参考值/梯度：固定作者函数在单匹配情况下与稳定移植式比较；保持t固定的有限差分；单独验证t不向框/置信度目标链传梯度，负项p²梯度保留。
2. 边界：IoU 0/1、logit大幅正负、空GT/空匹配、多GT、多类别接口及低IoU正样本；实际研究仍为单类。
3. 路由：只有最终普通loss_ce被替换，其余分类/回归/Mask项与原生一致；Matching与Torch RNG一致，未重复指派；MSSL损失及其梯度与V1定义一致。
4. 真实GPU：对固定单框、多框增强样本记录加权正负项、t分布、分类头梯度及AMP数值；移除训练Criterion后推理与同权重原生结果一致。
5. 两种配置各约50迭代smoke及权重重载/源域验证。Smoke只判工程健康，不按短跑AP淘汰方案或调参数。正式训练从共同初始化重新开始。

明确的实现错误可以修复，保留失败记录并重新验收；方法表现不好不作为换公式或调参的理由。测试与GPU验收未通过，不进入正式训练。

## 6. 评估与决策

主指标继续为总体bbox AP；完整报告AP50/AP75/AP90/AP95、候选覆盖、同GT最高分IoU差、质量错排、官方重复FP，以及原融合和固定框分类分数诊断。所有新组使用同一诊断定义，不能只挑有利评分路径作正式结果。

源域验证是开发结果。两组全部完成后，建议在预定的已观察PolypGen1473张队列上各评估一次，作为外部开发复核，使用源域选定权重、不重调系数/融合/阈值，不再扩展一轮广泛目标域归因。PolypsSet/PolypDB继续保留，不用于本轮选择。

至少分别报告（均以同一数据上的AP点计算）：

```
Q在原生基线上的增量：C-A
Q在MSSL上的增量：D-B
Q背景下MSSL的增量：D-C
描述性交互：(D-B)-(C-A)
```

不只凭D>B宣布MSSL被增强。若C、D均改善但D与C接近，收益可能主要来自成熟Q，MSSL新颖性未因此增强；若D相对B和C均有价值，才有理由继续研究结合。若回退或收益不清，保留V1，不自动换另一种Q、扩大作用层或叠加局部对比/DCNv4。源域变好、外部回退时如实报告，不能通过目标域重选权重保住方案。

最终层移植只是有限假设：其他层仍使用硬标签且存在共享参数，可能削弱软质量目标作用。因此阴性结果不否定完整Align-DETR或全部质量学习，阳性结果也不证明收益全部来自排序。单Seed不能建立交互的统计稳定性，GT辅助+2.632点不作可达目标。

## 7. 审查结论

| 维度 | 结论 |
|---|---|
| 贡献 | 成熟质量组件先作对照；暂不新增“Mask质量创新”的论文主张 |
| 清晰度 | 参考版本、公式、detach、正负样本、分支和归一化明确 |
| 实证 | 诊断支持有限投入，不承诺AP增幅；两个新完整训练形成2×2矩阵 |
| 完整性 | 实现、验收与队列状态见执行记录；独立外测/跨Seed仍待后续安排 |
| 设计 | 保留一对一语义与原生融合，承认最终层适配和损失尺度的局限 |
