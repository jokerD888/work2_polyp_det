## 2. 问题②：异常前那次 optimizer 更新到底改变了什么？——更新量异常放大，但精确梯度归因受事故限制

episode 逐 iter 参数更新范数（全参数 L2，直接量测，与裁剪钩子无关）：

| iter | raw CE | update_norm |
|---|---|---|
| 2785–2792（基线） | 0.02–0.70 | **0.23–0.26** |
| 2789 | 0.70 | 0.94（首次抬升） |
| 2793 | 1.16 | 0.79 |
| 2794 | 0.42 | **0.74** |
| **2795** | **10.27** | **1.66（全程最大）** |
| 2796–2812 | 0.3–3.7（震荡衰减） | 1.49→0.40 |

可确认的事实链：CE 在 2793 开始抬升（1.16）→ 2794 的损失读数正常（0.42，但该读数先于其参数
更新）→ **2795 的损失读到 10.27：权重在 2794–2795 的更新中已被破坏** → 随后 ~30 iter 更新量
持续放大（1.66→0.4 递减）并逐步恢复。触发不是单点：2789 起更新量已脱离基线。
**受事故限制的部分**：分模块梯度范数的"裁剪前全局值"因钩子缺陷记录为 0（分模块值真实），
无法给出 2794 那一步的精确梯度向量归因——这需要在未来带修复钩子的 run 中再捕获一次。

## 3. episode 的形态学新发现

- **振荡型而非平台型**：10.27→1.49→2.12→1.24→1.72→3.71→2.01→…，非单调恶化。
  此前设定的"连续 3 iter ≥2.0"触发条件因此未命中（触发器漏捕，快照缺失——已记为教训：
  触发应为"任一 iter ≥2.0 + 冷却"，未来 run 采纳）。
- **位置复现、幅度不复现**：本次 episode（2793–2822）与历史 2749 坍塌 episode（2699–2739）
  在同 seed 同数据序列的邻近位置——数据相位有贡献；但幅度与后果（坍塌与否）不同——
  随机分量主导结局。
- **选点完全翻转是常态**：SCDA 回归选点在同图相邻重访间的完全翻转率 78,354/86,087（Box-Gated
  diag）与 86.5%/88.4%（两个 LR run）——**与 LR 无关、与坍塌无关的固有现象**（H2 的修正：
  选点切换持续存在，但它既不随 LR 消失也不直接导致坍塌；它对训练的实际影响需其它机制解释，
  例如梯度方向的持续抖动而非突变）。

## 4. 事故记录：诊断 run 在无梯度裁剪下训练（影响边界）

- 缺陷：裁剪钩子把调用方的生成器耗尽后再传给原函数 → 裁剪空转。**两个诊断 run 实际无裁剪**
  （暴露：global_pre=0.0 而分模块范数正常；验收只查了"字段存在"，未查"值>0"——已记教训）。
- 影响：诊断 run 的 **AP（64.089/66.267）不可与裁剪协议的历史 AP 直接比较**；episode 动力学
  （更新量 1.66 等）是无裁剪条件下的测量。
- 不受影响：num_boxes 结论、选点翻转结论、episode 形态记录、数据顺序/RNG 隔离验证。
- 处置：钩子已修复（材料化列表传入原函数；单测 + 生产双验证 pre=138,016→post=0.01）；
  修复后启动的 LR 对照 run 使用正确裁剪，其结论不受本事故影响。
- **意外收获**：修复后首次量测到该管线的真实梯度量级——**iter 14 裁剪前全局范数 ≈138,000**
  （两个不同配置一致），训练中期分模块范数 backbone≈226–327、其余≈105–139——裁剪值 0.01
  在此管线是极端强约束；AdamW 二阶矩在稳态抵消裁剪、在瞬态放大更新，与"episode 持续数十 iter
  后自恢复"的形态吻合。

## 5. 根因判定（更新）

1. **坍塌 = 真实的权重瞬态破坏 + 自恢复**（本轮 2795 episode 的逐 iter 直接观测；
   评估链此前已排除）。
2. **触发因素不是 num_boxes**（①否定）；**不是选点切换的离散突变单独致因**（切换是常态，
   坍塌是稀有事件）。
3. **最可能机制**：高 LR 下个别 batch 的损失/梯度扰动经 AdamW 瞬态放大（裁剪 0.01 名义上
   限幅，但二阶矩归一化使稳态裁剪近乎失效，瞬态窗口内更新可达基线 3–7 倍）→ 权重短暂破坏
   → 数十 iter 自恢复。**LR 对照实验直接支持放大条件是 LR**：1e-4 下两个 run 在同一训练区间
   300 iter 后 CE 最大仅 1.92/1.60，零坍塌（`lr_comparison_20261017.md`）。
4. **仍缺的证据**：修复钩子下的 episode 梯度归因（需要未来一次带正确钩子的 run 再捕获）；
   多 seed 重复。已给出的可执行防治：**将 BASE_LR 降至 1e-4（协议内、无需改方法）即可消除
   观测到的坍塌形态**。
