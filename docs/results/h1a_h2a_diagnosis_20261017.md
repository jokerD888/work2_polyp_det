任务与判定标准见用户方案。工具与原始数据：`runs/_launcher/diag-h1a-h2a-20261017/`
（h1a_results.json / h1a_pergt_*.json / h2a_results.json，脚本 run_h1a.py / run_h2a.py）。
未启动任何训练；未修改任何方法代码（本轮零代码改动，仅新增诊断脚本）。

统一设定：F-Reg-Quality LR=1e-4 协议；数据为 880 张训练图各做一次确定性 LSJ 增强

测量；模型以 payload 仪表化的 `SCDAProposalDecoder` 构建（零新增参数，两份 checkpoint

## 1. H1-A：三阶段 Box 质量（每 GT 最优 IoU，879 图 / 934 GT）

| 阶段 | Clean A | F-Reg-Quality | Δ |
|---|---|---|---|
| E：Encoder Top-300 raw box | 0.8912 | 0.8890 | **−0.002（无差异）** |
| E：SCDA 选中的非 Top 候选（≤4/GT） | 0.4001（33.1%≥0.5） | **0.6811（80.0%≥0.5）** | **+0.281** |
| M：Mask2Box 初始化（同 300 query） | 0.8907 | 0.8884 | **−0.002（无差异）** |
| D：Decoder 最终（全 300 query） | 0.9342 | 0.9352 | +0.001（无差异） |
| D：按分数 Top-10 的最优 | 0.9327 | 0.9332 | +0.001（无差异） |

- 934 个 GT 中 100 个（10.7%）没有任何 SCDA 合格候选（覆盖/有效性门控后为空）。
- 同 query 保持率：`P(D≥0.5 | M≥0.5, 在 argmaxM 处)` Clean A=0.121 vs F-Reg=0.834
  ——两个模型对"哪个 query 承载最优框"的分配不同，但**每 GT 最终质量完全相同**。
  `E==M argmax` 一致率两模型都只有 ~0.37–0.40：mask2box 本身就会重排 query 排名。
- 相关性：M_best~D_best r≈0.91–0.93（强），但这是"两模型内部"的强相关；
  **模型之间 E/M/D 三阶段分布逐项重合**。

### H1-A 结论（回答方案中的三问）

1. **SCDA 改善了它自己监督的那批候选**（0.40→0.68，辅助目标本身被学到了），
   **但完全没有改善进入 Decoder 的 Top-300 raw box**（0.8912 vs 0.8890）。
2. **Raw 池（非 Top 部分）的改善没有传导到 Mask2Box 初始化**（0.8907 vs 0.8884）。
   结构性原因：Top-300 由分类分数选出，F-Reg-Quality 的 λ_cls=0，
   **SCDA 没有任何通道把它改善的候选送进 Top-300**；mask2box 只消费 Top-300 query
   的预测 mask，而 Top-300 query 从不被 SCDA 监督（Top-Q 排除是方法定义）。
3. Mask2Box 质量与最终质量强相关（r≈0.92），但两个模型在每个与 Decoder 相连的
   阶段上分布重合——相关性存在，**SCDA 带来的阶段间改善不存在**。

**判定：H1 的"监督位置与检测管线隔离"得到支持，且比"Mask2Box 切断"更精确——
隔离发生在更上游的 Top-300 准入（分数门控 + λ_cls=0），即使关闭 mask2box，
Decoder 拿到的 Top-300 raw box 也与 SCDA 训练无关。**

## 2. H2-A：固定权重梯度竞争（24 固定 batch × bs16，fp32，无 optimizer.step）

| checkpoint | ‖g_S‖ | ‖g_N‖ | r_S/N | cos(S,N) | cos(S,E) | cos(S,D) | cos(S,D+DN) |
|---|---|---|---|---|---|---|---|
| init（随机头） | 0.092 | 137,915 | ~1e-6 | +0.000 | +0.028 | +0.028 | +0.042 |
| best@4674 | 1.550 | 144.7 | **1.25%** | −0.027 | **−0.198** | +0.005 | −0.038 |
| ckpt@5224 | 1.585 | 122.3 | 1.42% | +0.012 | −0.012 | +0.007 | +0.017 |
| final@5499 | 1.580 | 120.2 | 1.41% | +0.012 | −0.017 | +0.006 | +0.001 |

- **真·中期 checkpoint 缺失**（keep-2 只保留 5224/5499 + best4674），按方案要求如实
  声明；best4674 是最早的可用训练态（87% 进度），更早阶段的梯度方向未测量。
- 分模块（按占 ‖g_S‖ 的范数比；平方和≠全局范数）：
  - **共享 `_bbox_embed`：g_S 的 74%**（‖g_S‖≈1.15 vs ‖g_N‖≈36–39，局部相对强度 ~3%）。
    cos(S,N) 在该桶：best4674=**−0.150**，5224=+0.012，5499=+0.007。
  - Pixel Decoder（含 input_proj，其注册名在 pixel_decoder 下）：~46%。
  - enc_output：~42%（cos 在 −0.14~+0.03 之间小幅波动）。
  - Backbone：~23%（cos +0.02~+0.03）。
  - class_embed / mask_embed / transformer decoder 主体 / label_enc：**g_S = 0**（与理论一致：
    SCDA 只经 raw_box 路径反传）。
- cos(S,D)（Decoder box 梯度）全程 +0.005~+0.011：**共享头上没有任何可测的对抗方向**。
- cos(S,E)=−0.198（best4674）是唯一超过 |0.15| 的负值，且在 5224/5499 消失——瞬态、微弱。
- AMP fp16 交叉核对（best4674, batch0）：r=2.0%，cos(S,N)=−0.10，cos(S,E)=−0.26——
  结论不变，无符号翻转。
- 实际 AdamW 合成更新另由训练 run 的 diag 记录覆盖（逐 iter update_norm 与裁剪前后
  梯度范数）；本诊断的独立梯度关系不直接等同于真实更新，按方案注明。

### H2-A 结论（对照方案的解释表）

- "SCDA 梯度很小"：**成立**。全局 1.3–1.4%，共享头局部 ~3%。
- "与原生梯度多数同向"：不成立，是**近正交**（|cos|≤0.03）而非同向。
- "经常反向且相对强度不低"：**不成立**。唯一负值是 best4674 处 bbox_embed 桶的
  −0.150 与 S~E 的 −0.198，幅度小且在后续 checkpoint 消失，不构成持续竞争。
- "方向随阶段变化"：存在轻微阶段依赖（S~E 由 −0.20 → 0），但方向翻转幅度小。

**判定：H2（梯度竞争损害共享回归头）没有得到支持。**

## 3. 两项诊断合并后的机制图景

SCDA 在 F-Reg-Quality（λ_cls=0）形态下是一个**与检测管线结构性隔离的孤岛**：
它把自己选中的非 Top 候选几何质量从 0.40 提到 0.68（辅助损失有效），
但这些候选（a）因分数门控无法进入 Top-300，（b）对 Top-300 几何零外溢，
（c）经共享头的参数耦合太弱（1.3%、近正交）不足以改变 Decoder 行为。
这与 LR=1e-4 下 SCDA−CleanA ≈ −0.47（噪声范围内 ≈0）的 2×2 结果一致：
**监督被学到了，但没有可用的传导路径把它变成检测收益。**

## 4. 对下一步因果消融的含义（供决策，未启动）

- 方案中的 H1-B（关闭 mask2box 的 2×2）：按本诊断预测很可能仍然 ≈0——因为
  mask2box 关闭后 Decoder 初始化改用 Top-300 raw box（且该路径同样是 detach 的），
  而 Top-300 raw box 在两模型间并无差异。H1-B 仍可检验"mask 分支初始化 vs raw box
  初始化"本身的影响，但**不是** SCDA 增益的传导开关。
- 若要检验"孤岛"解释本身，最直接的单变量是给 SCDA 一个分类通道
  （λ_cls>0，让改善的候选有机会进入 Top-300）——但这属于方法修改，超出本轮授权。
- H2 路径的梯度隔离消融（阻断 SCDA→共享头直接梯度）：当前证据（1.3%、正交、无
  持续反向）不足以预期该消融产生可测差异，按方案"必须以 H2-A 测到有意义梯度竞争
  为前提"，**不建议花这笔训练预算**。
