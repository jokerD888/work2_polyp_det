## 1. C1：0.40→0.68 的构成（880 训练图，834 GT，~64 万 token 配对）

| 视图 | 结果 |
|---|---|
| 双方 union 合格池逐 token Δ(F-Reg−CleanA) | mean **+0.005**，p50 **−0.028**，改善比例 **40.3%**（近乎对称） |
| 按 level 分解 | level0 +0.106（97% 改善）/ level1 +0.080（73%）/ level2 +0.159（93%）/ **level3（最细，占 74% token）−0.042（23%）** |
| 固定 Clean-A 自选 top-4 索引 | Δ mean **−0.045**（仅 12% 改善；iou_ca 0.337 → iou_fr 0.293） |
| 固定 F-Reg 自选 top-4 索引 | Δ mean **−0.047**（iou_ca 0.441 → iou_fr 0.394） |
| 各自自选 top-4 的 best（=H1-A 口径） | 0.4001 / 0.6811（复现） |
| Top-300 成员 | **880/880 图全部不同** |
| 大改善 token（Δ≥0.1，n=5,712） | F-Reg 分类排名中位数 **13**（示例 rank 1/6/8/10/15…，IoU 0.9+） |

**回答方案三问：**
1. **0.40→0.68 中，同 Token 实际回归改善的份额：在双方各自的选点上为零甚至为负**；
   广泛的同 Token 改善只存在于**粗粒度层**（level0–2，占 26% token，+0.08~+0.16），
   最细层（74% token）系统性轻微变差。0.28 的差距主体是 **F-Reg 按"自身预测 IoU"
   重选了不同候选**——它选中的 token 在 Clean-A 下基线就更高（0.441 vs 自选 0.337），
   即"改写了 IoU 地貌 + 重新选点"，而非"同一批框被回归得更好"。
2. 改善是否出现在可能进入 Top-Q 的候选中：训练图上，**最大改善 token 的分类排名
   中位数为 13**（几乎都已在 F-Reg 的 Top-300 内）——即训练图上改写后的地貌确实被
   分数排序承认；但 **val 上同样的晋升失败**（见 B1：oracle rank 3014，Top-300 内
   最优占比从 67% 掉到 25%）。
3. "学到了辅助目标、但对最终检测贡献有限"——**成立且需加精确化**：回归改善是真实的
   （粗层、且泛化到 val：oracle 0.814→0.835），但（a）无准入通道使其进入检测管线，
   （b）Top-300 内质量反而略降（val 0.769 vs 0.781），（c）AP 持平（噪声内）。

| | CleanA | F-Reg |

**Mask2Box 对同 query 既不系统性改善也不损害（配对 Δ≈0，中位为负）**；它改变的是
"哪个 query 胜出"。Decoder 无法从坏初始化中救回（≈0.02–0.04），但 GT 通常由其它
query 承载，故这不直接等于 AP 损失。

## 3. 五个问题的回答（证据强弱标注）

1. **最可能限制性能的环节**（证据较强）：**分数-定位对齐 + 候选准入排序**——
   Clean A 分类分与 IoU 相关仅 0.141，31–67% 的 GT 最优候选未获与其质量匹配的
   名次；**其次是小目标表征**（AP_small=0，12 个小 GT 只检出 6 个，最细尺度层
   oracle≈0.01/同 Token 层面还随 SCDA 训练变差）。Mask2Box（配对 Δ≈0）与
   Decoder 定位本身（oracle 阶梯 E→D 仅 +0.03，好初始化占主导）**不是**主要瓶颈。
2. **SCDA 是否针对真瓶颈**：**否**。它改善的是准入边界之外的候选几何（真实、可
   泛化），而瓶颈在准入排序与小尺度表征；其唯一对准瓶颈的正向迁移（cls-iou
   相关 0.14→0.50）力度不足以改变 AP（1e-4 下 −0.47，噪声内）。
3. **是否继续 Encoder 一对多辅助回归**：以当前形态（λ_cls=0、覆盖门控选点）
   **不构成继续投入的理由**——回归目标被学到、但结构上无法进入检测管线；除非
   重新设计准入/监督位置（方法级修改，非本轮授权范围）。
4. **下一步最值得研究**（若继续）：按证据强度排序——(a) **小目标/最细尺度表征**
   （绝对短板，AP_small=0）；(b) **排序/置信度-定位校准**（Clean A 的 cls-iou 0.141
   说明"模型不知道自己哪个框好"，而 F-Reg 证明该对齐可被辅助信号拉动）； Decoder
   定位与 Mask2Box 排后在后。
5. **数据局限**：单 seed；val 同时用于历史 best 选择（本报告仅作诊断性证据，非
   泛化结论）；小目标层仅 12 个 GT，"AP_small=0"方向明确但幅度不精确；C1 的
   "训练图上改写 token 已入 Top-300"与"val 上晋升失败"并存，说明排名行为在
   分布间不一致，需多 seed/独立测试集才能定论。

## 5. 追加分析（回应审查意见，2026-10-17 同日；analyze_followup.py / b1_followup.json）

### 5.1 Δ_selection（准入质量损失，无需训练）

d_sel = 全 token oracle best − Top-300 内 best（逐 GT，val 130 GT）：

| | CleanA | F-Reg |
|---|---|---|
| Δ_sel mean / p50 / p90 | **0.034 / 0.000 / 0.120** | **0.066 / 0.039 / 0.203** |
| oracle≥0.5 但 TopQ<0.5 | 5/127 | 4/125 |
| oracle≥0.75 但 TopQ<0.75 | 12/110 | **19/115** |
| COCO-large (n=118) Δ_sel | 0.034 | 0.065 |
| COCO-medium (n=9) Δ_sel | 0.048 | 0.094 |
| COCO-small (n=3) | Δ≈0.005，但 **oracle 本身仅 0.005** | 同 |

**判定（按"Δ_sel 小则不动准入"的规则）**：Clean A 的准入损失中位数为 **0**；
F-Reg 的 Δ_sel 约为 Clean A 的 2 倍且集中在 0.75 档（12→19 个 GT），是 SCDA 训练的
**次级代价**，但绝对量仍小（p50=0.04）。→ **路线 B（Mask-aware + 多尺度监督），
不做 Query-aligned 准入改造优先。**

### 5.2 小目标口径澄清（AP_small=0 与 6/12 并不矛盾）

COCO-small（area<32²）在 val 上**只有 3 个 GT**（129 / 8 / 33 px²），其全 token
oracle best = 0.011 / 0.001 / 0.004——**encoder 对这 3 个微型息肉根本没有任何像样的
候选**，与准入排序无关。此前报告的 "6/12" 用的是 96² 分桶（其中 9 个实为 COCO-medium）。
小目标结论**降级**：n=3 只支持"极小目标无候选是上游表征/感受野问题"这一方向性观察，
不足以立项为主攻方向。

### 5.3 分数–定位相关性的口径变体（回应"0.141→0.503 如何统计"）

原口径 = 全部 100×120 个最终检测混合 Pearson（含大量 IoU=0 检测）。变体：

| 口径 | CleanA | F-Reg |
|---|---|---|
| cls 分数：池化 Pearson | 0.141 | 0.503 |
| cls 分数：**池化 Spearman（排名）** | **0.600** | 0.511 |
| cls 分数：仅命中框(@0.5) Pearson | 0.105 | **0.691** |
| maskq：池化 Pearson / Spearman | 0.188 / 0.171 | 0.324 / 0.182 |
| maskq：仅命中框 Pearson | 0.774 | 0.422 |

修正后的解读：池化 Pearson 被零 IoU 检测压低，**不能**直接当准入质量证据；
按排名相关，Clean A 的全局排序反而略优；F-Reg 的优势在**命中框内部的精度排序**
（0.69 vs 0.10）。"对齐改善"降级为方向性信号，且两模型各有侧重。
（两模型的表观矛盾——相关性更高却准入更差——由此消解：两者测的是不同人群。）
