## 2. 四个问题的回答

**Q1 降低 LR 后，CE 尖峰和 AP 坍塌是否减少？——是（两个配置一致）。**
- AP 坍塌：DCN 组合 1 次（@1924，31.70）→ **0 次**；F-Reg 本来 0 次，保持 0 次。
- CE episode：@1e-4 的两个 run 在 **iter 300 之后的原始 CE 最大值分别只有 1.92 / 1.60**——
  历史 4e-4 在同窗口（1900–2822）出现过中位数 2.6–2.9 的持续 episode（含一次 raw 10.27 量级的
  捕获，见诊断报告）。300 后的 CE 海拔系统性下降。
- 仅存的 ≥2.0 episode 都在 **iter 126–262**（warmup 刚结束的早期相位），两个 LR 下都存在
  （4e-4 的 139/159 尖峰同位置）——这是**训练相位现象，与 LR 无关，也不随 LR 消失**。

**Q2 DCNv4 组合在 1e-4 下是否重新正向？——负交互消失，但无正向增益。**
- @4e-4：DCN 组合比 F-Reg 低 **−1.41**；@1e-4：65.575 vs 65.571，**差 +0.004（相等）**。
- 同时 DCN 组合的坍塌与稳定性劣势全部消失（0 坍塌、衰减前均值 59.40 反超 F-Reg 的 57.85）。
- 结论：**DCNv4 的危害是"高 LR × 组合"的交互不稳定，不是 DCNv4 本身有害**——
  这正是此前假设的验证结果。是否能在 1e-4 下让 DCNv4 转正，本组数据不足以判断（差值为零）。

**Q3 是否存在 LR 过低导致的收敛变慢？——没有。**
- best checkpoint 反而更早：F-Reg 4674（vs 5224）、DCN 4399（vs 5500）；衰减前均值两组都更高。
- 代价体现在口径上：@1e-4 的 AP50 系统性低于 @4e-4（83.1 vs 84.6），AP75 系统性高于 @4e-4
  （F-Reg 74.433 为全项目最高）——低 LR 把"宽召回"换成了"高定位精度"，总 AP 略降 0.57。

**Q4 现有证据是否支持高 LR 是坍塌主因？——支持"高 LR 是 DCN 组合与 Box-Gated 类失稳的
必要放大条件"，但不是充分条件，且证据限于单 seed。**
- 支持：DCN 组合的坍塌在 1e-4 下消失；300 后 CE 海拔在 1e-4 下系统性下降；
  修复裁剪钩子后实测**该管线裁剪前梯度范数高达 ~138,000**（两个配置 iter14 一致）——
  4e-4 下 AdamW 二阶矩对裁剪的抵消存在瞬态滞后，是 episode 的合理物理来源。
- 反例与边界：Clean A（原生、4e-4、无 SCDA）0 坍塌——高 LR 单独不致坍塌，需要与辅助监督叠加；
  1e-4 下早期相位（126–262）episode 仍然出现——触发因素未被 LR 消除，只是不再升级为坍塌。
- 判定：**"高 LR × 额外监督模块"的交互是坍塌的主要条件**；单 seed、每格 1 次，不构成统计结论。

## 3. 三者辨析（学习率下降 / 稳定性改善 / AP 改善）

- **DCN 组合**：三者同时发生——稳定性大幅改善（0 坍塌、衰减前 +7.6）、AP 改善 +0.84，
  且与 F-Reg 的差距从 −1.41 收敛到 0。LR 是该组合此前失败的主因之一。
- **F-Reg-Quality**：稳定性改善（衰减前 +1.49、AP75 +1.65 全项目最高）但总 AP −0.57
  （AP50 −1.44）——LR 下降改变 AP 的结构而非"改善训练"；4e-4 的 66.143 仍是该配置最优单点。
- 两个 @1e-4 run 之间（F-Reg 65.571 vs DCN 65.575）完全打平——**在合适的 LR 下，
  DCNv4 适配器既不增益也不损害**。

## 4. 对主线的含义

1. **F-Reg-Quality 的最优单点仍是 4e-4 的 66.143**；若论文需要最稳的训练曲线或最高 AP75，
   1e-4 是可选项（65.571/74.433）。两个 LR 点都是合法协议点，选择取决于叙事重点。
2. **DCNv4 的"死刑"撤销**：其 4e-4 失败是 LR 交互问题。若后续重新评估 DCNv4，
   应在 1e-4（或 LR 敏感性扫描）下进行，并配多 seed。
3. **坍塌防治的最小手段**就是降 LR——不需要改损失/结构。1e-4 下 300 iter 后 CE 海拔 ≈1.9 以下、
  零坍塌，是当前最干净的训练配置。
4. 所有结论单 seed 点估计；AP 差异 0.5–1.4 在此前测得的有效噪声带（1–3 AP）边缘，
   多 seed 复核仍是必要条件。
