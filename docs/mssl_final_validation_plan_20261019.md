## 2. 两份建议的合并与修正

网页端建议的阶段划分合理；上一轮本地建议的CIoU只是优先候选，不应把“实现成熟”直接写成“代表最新最强方法”。只有一个CIoU对照也不能证明相对所有定位优化方法的优势。

三个不同问题需要不同证据：

| 问题 | 现有证据 | 接下来补什么 |
|---|---|---|
| 精细Mask及完整CDF有什么增量 | Box-CDF、Mask-static；当前单Seed点估计和探索性区间 | 如实保留不确定性，不增加同类替代组 |
| 与已有工作差在哪 | 已有DSC、GFL、Mask-aware指派等机制对比 | 围绕具体损失与监督路径定向查新 |
| 相对成熟定位方案是否值得采用 | 原生基线及已完成CIoU-Replace；PolypGen AP差值区间为正 | 已完成当前竞争验证；结论限定该实现和协议 |
| 在未参与开发的数据上是否仍有收益 | PolypGen已被反复观察 | 预先固定队列及协议的独立外测 |
| 是否跨训练随机性稳定 | 当前Seed42；图像Bootstrap不覆盖此项 | 仍为缺口，遵守当前暂不多Seed的决定 |

## 3. 先做：方法正文更新与定向查新

固定全部V1公式、常数、作用层级、可靠样本条件与原生推理。统一“方向性前景支持”术语。数学上的单侧支持条件不能放宽写成“多数支持在内侧”而仍声称原命题自动成立；有限精度饱和、联合训练和AP收益的限制继续保留。

定向查新覆盖三类：Mask条件框回归/重加权、形状引导检测、边坐标分布或CDF误差监督。每项对照记录监督来源、目标是否改变、损失形式、挂载位置、推理成本及已有实验，不以名称相似作重复判断，也不以未检索到作首次证明。此轮目的是输出机制差异表，不再重做大范围背景综述。

本轮补核的直接相关工作：

- [Mask-Based IoU for Bounding Box Regression Using Medical Images](https://dergipark.org.tr/en/pub/tjmcs/article/1423292)，2024，DOI 10.47000/tjmcs.1423292。
- 原文§4.1以目标Mask覆盖及框面积构造MbIoU；§4.2是选定图像/框位置的度量示例；§5明确将基于该度量的训练与测试列为未来工作。因此需要讨论其与MSSL的区别，但不把它列为已验证的成熟训练基线，不根据摘要断言其已有AP提升。
- [本地原始PDF](../research/final_validation_sources/mbiou_2024.pdf)及[提取文本](../research/final_validation_sources/mbiou_2024.txt)。PDF SHA256：`48ac59df1609868536248694d279747ecb70e6dd21dcf89cf1b7daf3f3b58cfc`。已阅读相关正文及结论，未复现实验，未完成穷尽查新。

## 4. 已完成：唯一新增的成熟对照（原选型记录）

优先候选为[CIoU论文与作者代码入口](https://arxiv.org/abs/2005.03572)，理由是已有明确训练应用和可审计定义、无需分布预测头、适配成本低。是否选它，需要在训练前完成公式、实现和作用层级核查；如定向查新发现更直接且可靠的方案，应在查看新外测结果前完成选择并记录理由。

对照原则：所有组保留共同GT Mask及原生Mask监督；“Box-only”只指新增或替换的定位优化使用Box信息，不指整个Mask DINO仅接受Box标注。

若采用CIoU替换GIoU，优先按原生框回归损失的标准调用路径替换，提前列清最终层、辅助层、Encoder和DN的覆盖范围，保留L1、匹配和原有损失系数。不能训练后才选择作用层，也不能为使MSSL胜出而故意缩减比较方法的使用范围。该实验与MSSL最终层额外项的结构不同，属于成熟替代方案比较，不是纯信息来源消融。原生Matching含GIoU成本时，保留该成本并明示，不把它与回归损失混称。

共同协议：Seed42、相同初始化及数据顺序规则、Kvasir880/120、50等效Epoch、相同优化和增强、相同源域最大bbox AP选Checkpoint。记录梯度尺度和数值健康，不按PolypGen反复调系数。继承官方部分与研究适配部分分别写明。不得声称该移植实验等价于原作者论文完整检测器复现。

只有一种新对照完整训练；不搜索一排IoU损失，不新增MSSL组合模型。

## 5. 历史备选：PICCOLO独立外测协议（申请已暂停）

优先审查[PICCOLO官方数据说明](https://zenodo.org/records/4279017)。其说明包含患者独立的官方划分、白光/NBI及病灶临床元数据；当前Zenodo页主要提供论文与readme，不能假定原图可从该页直接下载或已经在本机可用。

访问渠道已补核：[Basque Biobank官方页面](https://www.biobancovasco.bioef.eus/en/Sample-and-data-catalog/Databases/PD178-PICCOLO-EN.html)要求申请。官方病灶/患者/视频口径不统一，以实际包和元数据为准；另有void Mask，应在预测前固定评价规则。本机对照准备不等待审批。

推荐以官方测试集白光图像为主分析，NBI另作预先指定的成像条件迁移分析；两者的具体可用数量由元数据审计确定，不能按模型得分挑子集。若数据不可获得，应在评估前按标注来源、重叠风险和可用性固定其他外测集，保留选择记录。

评估前形成带哈希的协议，至少固定：

1. 数据版本、完整文件列表、官方划分、成像模式及排除条件；排除只依据数据质量规则。
2. 框来源、坐标端点约定、多病灶/连通区域处理、空图及ignore处理。Mask-derived Box明确标注，框转换不读取模型预测。
3. 与Kvasir及已有外测的精确/近重复检查；查不到重复不等于已证明跨库患者独立。
4. 固定模型名单：既有四组及唯一新增成熟对照；使用源域选定权重，原生推理及统一评估参数，不按目标域重选Checkpoint或阈值。
5. 主指标bbox AP50:95；AP75、AP90/95及尺寸/模式分组为次要诊断，均完整报告。
6. 能从元数据可靠关联患者/病灶时，按相应可靠分组做配对重采样；否则明示图像级限制。不从文件名猜患者。
7. 首次冻结评估后完整保留结果。若据此改方法，数据即进入开发过程，不能继续作为该改进方法未触碰的最终确认集。

数据审计及评估器检查可先做；模型指标在协议和对照方案固定后统一生成。这里“首次”指预定确认分析，不是禁止为修复可证明的评估实现错误而重跑；所有更正须保留记录。

## 6. 决策与工作量

当前顺序：已有方法和五组证据归档（完成） → 其他数据版本/标签/重叠审计 → 固定独立外测队列与模型名单 → 外测 → 论文结果收口。CIoU训练不重复安排；方法正文与近邻差异可同步整理，经验性结论依据完整结果。

若独立外测继续正向且竞争比较有价值，定稿V1；若只高IoU有一致收益，收窄贡献表述；若总体相当或变差，如实报告，再依据失败证据决定是否需要改进。不得因为某个结果未达到预期而自动启动V2、调参或更换“最终”数据集。

当前暂不增加多Seed。最终若主张跨训练随机性稳定，需要另行安排预先指定的配对重复；图像数量和Bootstrap均不能替代。跨架构普适性、实时性或最新最强性能不属于当前已经有证据的主张。
