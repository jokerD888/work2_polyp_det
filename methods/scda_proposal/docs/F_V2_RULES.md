# F-v2：用户确认的分区回归配额（2026-10-15）

本规则取代 F-v1 在回归集合中直接按 coverage 取前4点的定义。用户明确确认后实现；原始 DESIGN_SPEC.md、F-v1 配置、commit 4b59966 和全部既有实验记录保留。

对于可靠且有效的 GT j，先按原规则确定 owner、合法候选、排除原生 Top-Q，再令：

- H_j：coverage >= 0.75 的 owned 候选，按覆盖率降序、归一化中心距离升序、固定 (level,u,v) 排序。
- M_j：0.25 <= coverage < 0.75 的 owned 候选，使用相同排序。
- P_cls(j) = H_j[:2]。
- P_reg(j) = P_cls(j) 拼接 M_j[:2]。

两区间无交集；回归复用**实际选出的**分类点。核心或中覆盖率区间不足时，仅用该区间实际可用数量；不跨区间补位。没有核心点但存在中覆盖率点时，分类为空、回归仍可有至多2点。每 GT 内仍按各任务实际选点数取均值，随后按各任务全球有效 GT 数归一化。记录核心和中覆盖率缺额，区分被可靠性规则跳过的 GT。

`reg_selection: coverage_topk` 保留 F-v1 路径（默认，兼容旧配置）；`reg_selection: core_plus_transition` 显式选择 F-v2，当前只接受已确认的 .75/.25、2/4 设置。预设为 `configs/kvasir_v2.yaml`。不添加参数、预测头、软标签、额外排序分数或损失。

其余规则均沿用：Kvasir 官方 bbox 与880/120划分；仅原始单框图的裁剪语义 mask 参与 SCDA；精确 token 像素积分；任何 padding 交集即排除；GT 宽高归一化中心距离；共同 owner；不改变原生 Top-Q、Hungarian、DN、mask2box、mask/intermediate loss 或推理；lambda_cls=lambda_box=.05；同 ImageNet R50 初始化、batch4、AMP、512增强、100epoch/22000iter及原生优化器/val选best。

诊断时提高回归 coverage 下界到 .75 的反事实仍保留**同一策略、不跨区间补位**：F-v2 的中覆盖率区间为空，回归只剩原分类点。这与 F-v1 的“取前4个高覆盖率点”反事实不同；JSON 标明策略和反事实定义，不把两者混称为只改阈值且数量不变。

初始和成熟原生权重的128张训练样本中，121个可靠有效 GT 都有至少2个核心候选及至少2个中覆盖率候选，后者最少分别9/8个。只说明本次配额有候选来源，不证明整个数据集或未来增强都满额，也不证明 AP 会提高。中覆盖率可来自边缘、孔洞或粗尺度，不能直接称为定位质量更好的边界点。
